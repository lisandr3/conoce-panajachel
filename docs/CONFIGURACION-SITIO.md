# Configuración compartida

- data/site/identity.json: nombre, dominio, logo, responsable y contacto.
- data/site/navigation.json: enlaces, orden y submenús; enabled activa cada enlace cuando exista su página.
- data/site/footer.json: columnas, enlaces, descripción, créditos y contacto.

Las etiquetas están preparadas en es y en. Los datos y productos cartográficos se comparten entre idiomas.
Las columnas del footer están vacías a propósito y pueden añadirse o reordenarse.
En la siguiente etapa conectaremos estos JSON al compilador y las plantillas; todavía no actualizan una página por sí solos.
