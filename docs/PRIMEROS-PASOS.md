# Primeros pasos

1. Copia el contenido de este paquete dentro del repositorio local conoce-panajachel.
2. Conserva el README.md y .gitignore creados por GitHub Desktop: este paquete no los reemplaza.
3. En GitHub Desktop revisa los cambios y crea un commit: Estructura inicial del proyecto.
4. El siguiente paso es configurar el compilador y diseñar header y footer con tu logo.

Este paquete organiza el proyecto. Todavía no contiene un sitio ejecutable ni un despliegue.
No incluye .git, node_modules ni archivos originales del sitio de referencia.
